# ENGG*1420 - Campus Booking Event System - Phase 2
Complete System

Features and Functionality
- User Management
-     Hierarchy: Student, Staff, Guest.
-     Create/remove new users.
-     Click on user to view all ongoing event bookings.
  
- Event
-     Hierarchy: Workshop, Seminar, Concert.
-     Add/remove/update events.
-     Click on event to view all attendees and those waitlisted.
-     Search.
  
- Booking
-     Hierarchy: Confirm, Waitlist, Cancel.
-     Notification for when event is booked.

- Waitlist Management
-     Automatic waitlist promotion when spot opens up for next user.
-     Notification when attendee is removed.
  
- Saving
-     Changes that were made will save on windows close (x button).
-     On the next run, your changes should still be there.

Running Tests
-     Clone the repository and open it in IntelliJ IDEA.
-     Navigate to the test file (BookingManagerTest.java).
-     Run the test file by either:
      - Right-clicking the file and selecting "Run".
      - Clicking the green run arrow in the top-right corner in opened file.

Compile and Run
-     Clone the repository and open it in IntelliJ IDEA.
-     Ensure JDK and JavaFX are installed and properly configured.
-     Open Main.java 
-     Click "Run" to launch the GUI.
